# ScheduleFlow — منظّم الجداول التدريبية

أداة ويب لإعداد الجداول التدريبية لكل تخصص: عدد الشعب، إسناد المقررات للمدربات، توليد جدول مقترح بلا تعارضات، وجدول يدوي، مع التحميل بصيغتي Excel وPDF.

## محتويات المجلد

- `index.html`: الموقع كاملاً في ملف واحد.
- `README.md`: هذا الملف.

## النشر على GitHub Pages

1. أنشئي مستودعاً جديداً على GitHub، مثلاً باسم `scheduleflow`.
2. ارفعي الملفين `index.html` و`README.md` إلى المستودع من زر **Add file ← Upload files**، ثم **Commit changes**.
3. افتحي **Settings ← Pages**.
4. في **Source** اختاري **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغطي **Save**.
5. بعد دقيقة أو دقيقتين يظهر رابط الموقع أعلى الصفحة، بالشكل:
   `https://اسم-المستخدم.github.io/scheduleflow/`

## ملاحظات مهمة

- **الحفظ:** العمل يُحفظ تلقائياً في متصفح كل مستخدمة على جهازها. للنقل بين الأجهزة أو للحماية من الضياع استخدمي زري «حفظ نسخة» و«استرجاع».
- **الإنترنت:** الموقع يحتاج اتصالاً لتحميل الخطوط ومكتبات Excel وPDF.
- **الخصوصية:** المستودع العام على GitHub يكون مرئياً للجميع. الملف لا يحتوي إلا أسماء المدربات والمقررات المدخلة فيه، لذا يُفضّل التنسيق مع تقنية المعلومات قبل النشر، أو جعل المستودع خاصاً إن كان حسابك يتيح GitHub Pages للمستودعات الخاصة.
- **التحديث:** عند أي تعديل على الموقع ارفعي `index.html` الجديد مكان القديم بالطريقة نفسها.
